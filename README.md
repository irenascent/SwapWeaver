## Installation

1. Clone the repository: `git clone https://github.com/irenascent/SwapWeaver.git`
2. `cd SwapWeaver`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure SwapWeaver, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
